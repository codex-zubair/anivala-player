1. GOAL
========================================================================
Ship a free, ad-free, 100% offline local media player for Android and Android
TV that scans and plays animation/video files already stored on the user's
device, with an automated "Continue Watching" dashboard that remembers
playback positions locally. No backend, no network, no accounts.

Policy-compliant posture: no INTERNET permission, no ads, no analytics,
no tracking. All data stays on-device.

3. KEY FACTS / DECISIONS
========================================================================
- Name chosen: "AniLoom" (Play/App Store search showed no exact match;
  a formal trademark check is still advisable before publishing).
- Package: com.codexzubair.aniloom (as requested by the user; permanent).
- GitHub owner: codex-zubair (existing account, existing SSH key).
- Scope v1.0: local scan + play + Continue Watching. Android + Android TV.
- No backend. No INTERNET permission. No ads, no analytics.
- Storage access: scoped READ_MEDIA_VIDEO (Android 13+) /
  READ_EXTERNAL_STORAGE (<=12). NO MANAGE_EXTERNAL_STORAGE.
- Local storage uses shared_preferences only (library index + resume).
- Signing keystore is git-ignored; password stored in android/key.properties
  (also git-ignored). KEEP THE .jks SAFE - losing it blocks Play updates.
